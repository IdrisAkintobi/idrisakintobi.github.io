# Idris Akintobi — Portfolio

Personal portfolio website for **Idris Akintobi**, Senior Backend / Full-Stack Engineer. Built with Next.js 15, Tailwind CSS, and TypeScript as a fully static, zero-runtime export.

- **Live Site:** [idris.akintobi.ng](https://idris.akintobi.ng)
- **GitHub Pages:** [idrisakintobi.github.io](https://idrisakintobi.github.io)

---

## 🚀 Quickstart

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Create production static export (./out)
npm run build
```

---

## 🌐 Deployment

### GitHub Pages
Automated via GitHub Actions on push to `main` ([`.github/workflows/deploy.yml`](.github/workflows/deploy.yml)).

### Cloudflare
Deploy the static export directly using Wrangler:
```bash
npm run deploy
```

---

## 🛠 Tech Stack

- **Framework:** Next.js 15 (App Router, Static Export)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React & Handcrafted SVGs
- **Language:** TypeScript
